# data

Checked into git on purpose. This is the season's permanent record, and git is
both its audit trail and its only backup.

```
snapshots/fantrax/YYYY-MM-DD/   one directory per capture day
  getLeagueInfo.json            raw fxea responses, verbatim
  getTeamRosters.json
  getStandings.json
  getDraftResults.json
  getPlayerIds.json
  manifest.json                 capturedAt, leagueId, per-read ok/error
mappings/                       generated by scripts/, audited by hand
```

## Why capture at all

Fantrax serves current state. It will not tell you in March who was benched in
October, and there is no archive of our league anywhere — it sits behind a league
id nothing crawls. Roster history therefore exists only if we write it down as it
happens, and a day missed is a day gone.

## Cadence

Weekly until the draft (10 Oct 2026), daily after it — the roster stops moving
between captures and starts moving constantly. `npm run capture:status` reports
the age of the last capture and exits non-zero when it is overdue.

Known limitation: at daily granularity, a player added and dropped the same day is
invisible. Worth revisiting once the draft shows how much same-day churn there is.

## Rules

Raw in, raw out. The capture writes exactly what the provider returned and derives
nothing — what we can ask later is limited by what we kept, and deciding today
which fields matter is the cheapest way to be wrong about that.
